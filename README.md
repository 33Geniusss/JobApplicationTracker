# 投递簿 · 本地求职申请记录

**简体中文** | [English](README_EN.md)

在这台 Windows 电脑的浏览器中记录已申请的公司和岗位。无需账号、无需联网、无需安装数据库，运行时只使用 Python 标准库。

## 启动与停止

1. 打开项目文件夹。本机路径为 `D:\Study\Master\JobApplicationTracker`；如果克隆到了其他位置，请使用你自己的项目路径。
2. 双击 **`start.bat`**。浏览器会自动打开 <http://127.0.0.1:8765>。
3. 正常启动时，保留启动窗口；最小化即可。重复启动会打开已有服务，不会创建另一套记录。
4. 双击 **`stop.bat`**，或在启动窗口按 `Ctrl+C`，即可停止服务。关闭网页标签不会停止服务。

需要 Python 3.10 或更新版本。这台电脑已使用 Python 3.13.13 和 Microsoft Edge 验证。普通使用不需要执行 `pip install`。

也可以在 PowerShell 中启动：

```powershell
cd D:\Study\Master\JobApplicationTracker
python app.py
```

如果默认端口被其他程序占用：

```powershell
python app.py --port 8766
# 使用后停止这个端口的服务：
python app.py --stop --port 8766
```

服务只监听 `127.0.0.1`，局域网中的其他电脑无法访问。页面的文字、样式、脚本均保存在本机，没有外部字体、统计或云端存储。点击你保存的岗位链接会打开外部招聘网站。

## 记录和查询

- 点击“记录新申请”，填写**公司名称和岗位名称**。岗位网址可留空；填写时需要完整的 `https://` 或 `http://` 地址。
- 申请日期默认为电脑浏览器的当天，可改为实际投递日期。
- 公司输入框支持已有名称、常见中英文别名以及新公司。只有保存申请后，新公司才会加入列表。
- 搜索栏只输入公司名称即可查看所有已申请岗位。不区分英文大小写，忽略首尾空格，支持部分名称和预设别名。例如输入 `英伟达`、`nvidia` 都会找到 NVIDIA。
- 点击左侧公司可以只查看该公司。右侧“筛选岗位名称”可以进一步检查某个岗位是否申请过。
- 未申请过的公司显示“尚未申请该公司”。即使公司在预置名录里，也不代表已申请。
- 同公司、同岗位名称会提示重复。确认属于其他批次或另一次申请时，勾选提示框后可以继续保存。
- 每条记录支持编辑、删除、打开岗位网址。删除需要确认。
- 键盘按 `/` 可快速聚焦公司搜索。按 `Esc` 可关闭弹窗。

公司名称通过 Unicode 标准化、英文大小写和空白处理来匹配；预设别名也参与匹配。Google / Alphabet、Amazon / AWS 等按求职中常用的公司组归档，GitHub 等独立列出的招聘品牌保留单独记录。系统不会自动猜测拼写错误或合并任意相似名称。

## 申请状态

- 新申请和升级前已保存的申请默认进入 `reviewing`。
- 按**申请日期**与电脑本地当天日期的日历天数差计算：相差 30 天时仍为 `reviewing`，相差 31 天及以上自动显示 `long reviewing`。补录旧申请也按原申请日期判断。
- 每张申请卡片的“申请状态”下拉框可直接改为 `refused` 或 `accepted`，选中即保存；编辑申请的弹窗内也可以修改。
- `refused`、`accepted` 会一直保留，不受 30 天规则影响。改回 `reviewing` 后恢复按申请日期自动判断，超过 30 天仍显示 `long reviewing`。
- `long reviewing` 是等待审核状态随日期自动计算的结果，不需要手动设置。修改申请日期后会重新计算。
- 每次打开或刷新页面都会计算状态。页面一直开着时，每分钟检查日期是否跨天；从后台或电脑休眠恢复后也会检查，不必让软件连续运行 30 天。

升级时只给数据库增加状态列，已有记录编号、公司、岗位、网址和日期保持不变。

## 公司候选名单

随软件提供 **300 个候选公司/招聘品牌名称**，覆盖 AI / ML、软件与云计算、芯片与计算机硬件、机器人与自动驾驶、互联网与金融科技及安全。大型公司和早期小公司均有收录。

- **275 个**为人工整理的美国科技求职候选名称；没有逐一核验当前经营、独立法人及招聘状态。
- **25 个**美国早期 AI/ML 公司名称及所在地提取自 [YC 官方 Machine Learning 公司目录](https://www.ycombinator.com/companies/industry/machine-learning)，每条保留对应的官方公司资料链接。
- 大型科技/芯片公司整理时参考了 [Nasdaq 科技指数资料](https://www.nasdaq.com/NDXT)。这些来源不是完整 300 家名单的逐条验证依据。
- 名单含子公司、被收购公司或仍常见的招聘品牌；美国公司范围以求职用途整理，不能当作法律注册地数据库。名单不是正在招聘公司的清单，也不保证穷尽美国科技公司。
- 名录数据在 `companies.json` 中；其中 `provenance` / `provenance_en` 说明来源，`aliases` 提供别名。运行时完全离线读取。
- 用户可随时通过新增申请加入未收录公司。预设名录本身不创建任何申请记录。

`scripts/build_company_catalog.py` 是开发时的生成脚本，需要联网和 `beautifulsoup4`，普通用户无需运行。重新生成名录只更新 JSON；现有数据库中的已存在公司不会被覆盖。修改现有公司别名应先备份，再针对数据库做迁移，不能通过删除用户数据库来更新。

## 数据与备份

所有数据实际保存在：

```text
D:\Study\Master\JobApplicationTracker\data\applications.sqlite3
```

记录保存在 SQLite 文件中，而不是浏览器缓存。重启软件、关闭电脑、清理浏览器缓存都不会清除该文件。不要删除 `data` 文件夹。

点击“备份与恢复”：

1. **下载备份**：导出 JSON 文件，包含全部申请记录的公司、岗位、网址、申请日期、创建时间、状态和记录编号。建议把文件另存到安全位置。
2. **选择备份文件**：显示待恢复记录数量；确认合并后才写入。
3. 新记录合并加入；记录编号和内容都一致的记录跳过。
4. 如果同一编号的记录后来已被编辑，导入会提示冲突并整体取消，避免旧备份覆盖新修改。
5. 文件格式或任何记录有错误时，整次导入回滚，不会只导入一部分。限制为 20 MB / 50000 条记录。

JSON 备份用于恢复申请记录，并恢复记录关联的自定义公司；不包含已经没有任何申请记录的自定义公司，也不包含预置名录的历史版本。若要原样保存整个数据库，先停止服务，再复制整个 `data` 文件夹。数据库级恢复需先停止服务并保留当前文件副本，再替换 `applications.sqlite3`。

新版备份格式为 version 2，包含手动状态；等待审核统一保存为 `reviewing`，恢复后按申请日期判断是否显示 `long reviewing`。仍可导入旧版 version 1 备份：新恢复的记录默认 `reviewing`；已存在且其他字段一致的记录会跳过，保留当前手动状态。新版备份与当前记录状态冲突时，整次导入取消。旧版软件不能导入 version 2 备份。

## 验证

后端使用标准库测试，不额外安装依赖：

```powershell
python -m unittest discover -s tests -v
```

浏览器验收脚本需要开发依赖 `playwright` 和已安装的 Microsoft Edge：

```powershell
python -m pip install playwright
python tests/browser_check.py
python tests/browser_status_check.py
python tests/browser_language_check.py
```

浏览器测试使用临时数据库，覆盖首次打开、公司名录、中文别名、新增申请、重复提醒与确认、编辑、岗位筛选、无记录查询、页面刷新、删除确认、备份下载与恢复、无效备份以及窄窗口布局。截图保存在 `test-results/`，其中的演示数据不会写入正式数据库。

状态测试覆盖第 30/31 天的边界、页面保持打开时的自动更新、手动结果、持久保存和恢复自动审核。语言测试覆盖英文流程、语言选择记忆、双语数据共享、软件校验提示和窄窗口布局。

## 文件结构

```text
README.md / README_EN.md      中英文对照说明
app.py                        本地 HTTP 服务、SQLite 存储和输入校验
localization.py               服务端提示翻译、公司名录双语字段
start.bat / stop.bat           Windows 启动和停止入口
companies.json                300 家公司候选数据及来源说明
static/                       本地页面、样式和交互
static/locales/               中英文语言资源
data/applications.sqlite3     实际申请数据（第一次启动时创建）
tests/                        后端与浏览器验收
scripts/                      名录生成工具
```

若页面提示无法连接，请重新启动后刷新。若修改了文件而页面未更新，按 `Ctrl+F5`。软件为单用户本机工具，不提供云同步、自动抓取岗位或自动投递功能。
